# Security

## Reporting a problem

Please report security problems privately through
[GitHub's private vulnerability reporting](https://github.com/k2lhu/achat/security/advisories/new),
not in a public issue. You should get a reply within a week.

In scope: anything that could expose API keys or conversations, for example keys reaching
logs, process arguments, the screen or disk; the config file permissions; requests going
anywhere other than the configured `base_url`s; or attachments being read from places the
user didn't choose.

## Supported versions

Only the latest release gets fixes.
